## 建立 .NET EtherCAT 主站工程（D:\Library\EtherCAT）

- 需求：.NET 实现 EtherCAT 主站 + Avalonia 界面 + 基于 ESI 描述文件的节点扫描 + 伺服控制 + IO 读写。
- 交付：`EtherCAT.slnx`（.NET 10 SDK 生成的是 .slnx 不是 .sln），三个项目：
  - `src/EtherCAT.Core`（net8.0 类库）：协议层（帧/数据报）、Npcap 链路、仿真链路+仿真从站、主站（扫描/SII/CoE/PDO/SM/FMMU/状态机/LRW 周期）、ESI 解析、CiA402 与 IO 设备层。
  - `src/EtherCAT.App`（net8.0 + Avalonia 11.3.22 + Avalonia.Themes.Fluent）：节点扫描/伺服/IO/PDO 监视/日志五个页签。
  - `src/EtherCAT.Demo`（控制台冒烟测试）。
- 协议细节以 SOEM 源码为参考（通过 api.github.com 拉文件，raw.githubusercontent.com 在本机被墙）：
  - ESC 寄存器、SII 固定区**字地址**（vendor=8/0x0A=product/0x0C=rev/0x0E=serial，邮箱 0x18/0x1A/0x1C 为字地址；类别区起始字 0x40 = 字节 0x80）。
  - CoE 报文：邮箱头 6 字节 + CoE 头 2 字节 + 命令 1 + Index 2 + SubIndex 1 + 数据；SDO 上传请求 length=0x0A。
  - WKC：读 +1，写 +2（LRW 读写都有时 +3），SOEM 注释 "output WKC counts 2 times when using LRW" 已确认。
- 验证：控制台 Demo 5/5 通过（WKC 9/9、使能、PV 运动、IO 0x00FF/0xA5A5）；界面自检
  `dotnet run --project src/EtherCAT.App -- --selftest` 输出 selftest.log（3 从站/2 伺服/1 IO/24 PDO 变量/使能成功）。

## 踩过的坑

1. **自动增量寻址**：从站是「先 +1，等于 0 才响应」，主站第 n 个从站的 ADP = -(n)（第 1 个 = 0xFFFF）。
   一开始在仿真从站里写成「先判断再自增」，导致整个网络错开一站，扫描到一串全 0 身份。
2. C# 里 `ushort &= ~常量`、`byte &= ~常量` 会因常量负值编译失败，改成显式正掩码（如 `&= 0xF7`、`&= 0x87FF`）。
3. Avalonia 11 不随主包带 Fluent 主题，必须单独引用 `Avalonia.Themes.Fluent`；`WithInterFont()` 找不到就别用。
4. `dotnet new sln` 在 .NET 10 SDK 下生成 `.slnx`。
5. CiA402 `Enable()` 用「一次等 3 秒再写控制字」的写法会偶发失败；改成每轮按当前状态字重新下发控制字的收敛式循环后稳定。
