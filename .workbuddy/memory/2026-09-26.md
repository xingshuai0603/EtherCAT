## UI 扫描后三页空白 bug 修复
- 现象：仅点『扫描节点』后，PDO/伺服/IO 三个页签无信息（集合只在 Configure 成功后填充）。
- 根因：IsDrive/IsIoModule 扫描阶段已确定，但 slave.Outputs/Inputs(PDO变量) 与 Drives/IoModules/PdoVariables 集合要到 Configure->BuildVariables 才填充。
- 修复：Scan() 成功后立即 BuildDeviceModels()（伺服/IO 列表立即可见）；仿真模式自动 Configure+StartCyclic 一步到位；真实硬件模式不自动配置（安全），三页加空状态提示。
- 防御：CiA402Drive 的 SDO 兜底加 !_master.IsConfigured 保护，避免扫描后定时器每100ms对未配置从站刷 SDO。
- 新增 InverseBooleanConverter 与 HasDrives/HasIoModules/HasPdoData 属性用于空状态提示。验证：App --selftest 与标准/虚拟 Demo 全绿。
